# Design artifacts

Art-style mockups made before building the game. Each is a self-contained HTML page of
animated canvas mockups; open it in a browser.

| File | Mockups |
|---|---|
| `round1-art-styles.html` | Cinematic, Flight Plan (blueprint), Saturday Cartoon, Ship Console (amber) |
| `round2-art-styles.html` | Toybox, Comic Book, Cute Crew, Papercraft, Cel-Shaded |

## Decisions

- **Favourites:** Saturday Cartoon, Comic Book, Papercraft.
- **First build uses Saturday Cartoon**, plus:
  - the ghost ship, dotted trail and live readouts from **Flight Plan** (readouts can be toggled),
  - the icy planet from **Cinematic**,
  - the arrow and key hints from **Toybox**,
  - speech bubbles with lines from the film's docking scene, from **Comic Book**.
- Comic Book and Papercraft stay on the list as possible alternate skins.
