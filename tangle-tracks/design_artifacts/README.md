# Design artifacts

Art-style mockups for **Tangle Tracks**, a top-down train maze: flip the switches and turn the
turntable so the train reaches the station. Made before building the game. Open the HTML file in
a browser; every board on the page is playable.

| File | Mockups |
|---|---|
| `round1-art-styles.html` | Wooden Toy Box, Signal Box, Transit Map, Sketchbook (rough.js), Night Lantern, Toy Diorama (three.js) |

All six boards use the same 8 × 6 layout: 4 switches, 1 turntable, 2 crossings, 2 dead ends and a
station. The best solution takes two flips (turntable arrow to the right, then the switch next to
the station).
